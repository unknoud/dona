# Corna Redesign v4

Versão refinada do projeto com:

- PIN de 4 dígitos digitado pelo teclado, com linha ativa piscando em cada posição.
- Texto "Digite a senha".
- Clique em qualquer parte da tela bloqueada para abrir o PIN; clique fora do cartão para fechar.
- Botão "Desbloquear" transparente com texto que aparece ao mover o mouse sobre ele.
- Galeria horizontal contínua com inércia, roda/trackpad e arraste suave, sem setas nem snap por foto.
- Imagens sem arraste nativo e menu de contexto bloqueado na galeria.
- Sem favicon personalizado.
- Mantém as 10 fotos, coração/like, áudio e PIN original.
